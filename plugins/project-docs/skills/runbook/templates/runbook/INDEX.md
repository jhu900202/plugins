# Runbook 진척

본 표가 `installation/` + `implementation/` 의 모든 항목 진척 상태에 대한 단일 진실 소스다. frontmatter 에 status 키를 두지 않는다 — 이중 진실 회피.

| 영역 | 항목 | 파일 | 상태 | 갱신 |
|---|---|---|---|---|
| _(empty — 항목 추가 시 행 삽입)_ | | | | |

## 상태 키

- `draft` — 골격만 존재, 본문 placeholder
- `review` — 본문 작성 완료, 사용자 검토 대기
- `confirm` — 사용자 검토 후 명시 확정 (해당 커맨드는 점진적 추가 시점에 정의)

## 기록 규칙

- 새 항목 추가 시 행 삽입. 예: `| installation | 0_infra_bootstrap | installation/0_infra_bootstrap.md | draft | 2026-04-29 |`
- 갱신 일자는 `YYYY-MM-DD` 표기
- `installation/` 항목과 `implementation/` 항목은 한 표에 통합 — 영역 컬럼으로 구분
